# Case 03 · 用户不知道怎么表达 → 正交方向 + 自由描述通道

**演示目标**：规则 6 的完整落地，并演示"用户给出选项之外的第四条路"时应如何反应。

---

## 用户

> 我想弄个个人网站，但我不知道该怎么描述……你看着办吧。

## 内部盘点（用户不可见）

```
目标产物:     个人网站 [? 类型未定]
使用者/场景:  [?]
成功标准:     [?]
硬约束:       [?]
核心对象:     网站 [?]
风格质感:     [?]
用户状态:     "不知道怎么表达" → 触发 §4 方向择选 + §6.3 容忍度提升
```

**判定**：P0 全缺，且用户主动说不会表达 → **不直接出稿**（信息不足），但**也不连珠炮追问**。改为：1 个 P0 问题 + 一组正交方向。

---

## 第 1 轮（1 问 + 方向择选）

> 没关系，这个能一步步来。先确认一件事，顺便给你几个方向做参照：
>
> **1. 这个网站主要要帮你做成什么事？**（影响：整个站的结构，是简历、作品集还是接单入口）
>
> 如果暂时说不清，可以先看这四个**很不一样**的方向，挑一个"最像你想要的感觉"的，或者直接描述你自己的版本：
>
> | | 方向 | 它长什么样 | 适合什么目的 |
> |---|---|---|---|
> | A | **作品档案馆** | 大图为主，几乎没有字，按时间或系列排列 | 让人看完说"这人做的东西好" |
> | B | **一条长简历** | 从上到下一页读完：我是谁→做过什么→联系方式 | 找工作、让 HR 3 分钟了解你 |
> | C | **接单服务页** | 首页直接写清楚"我能帮你做什么、多少钱、怎么联系" | 让人看完就下单/询价 |
> | D | **个人日志** | 短文 + 随笔，更新频繁，风格随意 | 持续输出、建立个人表达 |
>
> —— 这四个只是一组参照坐标，**也完全可以都不是**，你用自己的话描述就行。

## 用户

> 其实都不太像……我想要那种，别人加我微信之前能先大概了解我这个人，但我不想天天更新，也不要像简历那么正式。

## 内部盘点（用户不可见）

```
目标产物:    介于 B 与 D 之间的"个人介绍页" [~ 由用户自述确认]
使用者/场景:  微信好友（潜在合作方）在添加前浏览 [✓]
成功标准:    30 秒内"大概了解这个人" [✓ 由自述推出]
硬约束:      不频繁更新 [✓] 不能像简历那样正式 [✓]
核心对象:     网站
风格质感:     [?]  ← 仍未澄清
用户给出选项外的路: [✓ 必须优先采用，不得拉回 A–D]
```

**关键动作**：用户否定了全部四个选项 → **不辩解、不引导回选项**，直接以他的自述为准。

---

## 第 2 轮（2 问）

> 那我按你说的来：一个"轻量个人介绍页"，不更新、也不像简历。还差 2 个：
>
> 1. 别人看完这页，你最希望他记住你的哪一面？（影响：首页第一屏放什么）
>    比如：做过的事 / 你在意的东西 / 你的做事方式 —— 或你自己说。
> 2. 你这页要不要放真实照片？（影响：整体是"真人感"还是"符号化"风格）

## 用户

> 记住我做事很靠谱吧。照片就算了，放个我做的木工小玩意儿的图就行。

## 内部盘点（用户不可见）

```
成功标准:    记住"做事靠谱" [✓]      风格质感: 真人感[✗ 已排除] → 物件/符号化 [✓]
输入素材:    木工作品图 [✓]
```

**停止判定（§6.1）**：谁用[✓] 要什么[✓] 怎么算成功[✓] 硬约束[✓ 不更新/非简历/无真人照片] → **足够。**

---

## 出口

```
# 任务 Prompt
1. 角色与目标
   设计一个轻量个人介绍页，让打算加微信的人在添加之前用 30 秒大致了解"这个人"，并留下"做事靠谱"的印象。
2. 输入
   素材：用户木工作品照片若干（无真人照片）
   自述：不频繁更新；不采用简历式正式排版
3. 约束
   - 单页结构，不做博客/日志模块
   - 不使用简历式时间轴与"求职式"表述
   - 不放真人照片，视觉主体为木工作品
   - 内容可长期不改（避免出现"最近更新""最新动态"等时间性栏目）
4. 输出格式
   单页信息结构：第一屏（一句话定位 + 一张木工作品图）→ 我做过的 2～3 件事（每件 1～2 句）→ 我在意什么 → 联系方式
5. 验收标准
   - 30 秒内读完并能复述"这人是做什么的"
   - 语气自然、无自夸形容词堆砌
   - 全页不含任何需要定期更新的模块

## 待确认假设
- "做事靠谱"通过"具体做过的事 + 结果"来体现，而不是通过"认真负责"一类形容词（由你自述推出，若不符请指出）
- 联系方式为微信二维码 + 一句加好友说明（未与你确认）
```

---

## 这个例子示范了什么

| 行为 | 对应规则 |
|---|---|
| 用户说"不知道怎么描述"→ 给 4 个方向而非直接出稿 | 规则 5、6 |
| 4 个方向按目的正交切分（档案馆/简历/服务页/日志），不是程度差异 | 规则 6 |
| 每个方向都写清"适合什么目的"，帮助用户判断 | 规则 6 |
| 明确写出"也完全可以都不是"，并保留自由描述通道 | 规则 6 |
| 用户否定全部选项 → 立即采用用户自述，不拉回选项 | 规则 4、6 |
| 用户排除真人照片，该决定直接进"约束"区 | 规则 4 |
| 全场 2 轮共 3 问，未因"不确定"而无休止澄清 | 规则 8 |
| "靠谱 = 具体的事"是我推的 → 只进「待确认假设」 | 规则 4 |
