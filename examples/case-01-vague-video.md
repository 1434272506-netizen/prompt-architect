# Case 01 · 模糊需求 + 「电影感」澄清（完整多轮）

**演示目标**：首轮不出稿、每轮 ≤3 问、P0 优先、模糊词正交拆解、七问按需取用、信息足够即停。

---

## 用户（第 1 句）

> 帮我写个短视频脚本吧，我们公司做智能门锁的，要**电影感**，**震撼**一点。

## 内部盘点（用户不可见）

```
目标产物:     短视频脚本 [?]      使用者/场景: [?]
成功标准:     [?]                 硬约束: 时长[?] 平台[?]
核心对象:     智能门锁 [?]  ← 用户已点明，但七问全空
风格质感:     电影感[模糊] 震撼[模糊]
待确认建议:   []
```

**判定**：P0 三项全缺 → 启动采访。风格词虽然显眼，但**先问目标**——同样的"电影感"用在招商片和用在抖音投放里是两条路。

---

## 第 1 轮（3 问，全 P0）

> 还差 3 个关键信息：
>
> 1. 这条片子发在哪、给谁看？（影响：时长、信息密度、能不能用专业术语）
>    可选方向：抖音/短视频信息流 / 官网首页品牌片 / 招商或展会放映 —— 也可以都不按，直接说。
> 2. 大概多长？（影响：能承载几个信息点）
> 3. 看完你希望观众做什么？（影响：全片的重心是"产品功能"还是"品牌信任"）
>
> （回答其中之一也行，其余的可以跳过。）

## 用户

> 抖音投放，30 秒左右。主要是让人记住我们这锁够安全。

## 内部盘点（用户不可见）

```
目标产物:     30s 抖音短视频脚本 [✓]   使用者/场景: 抖音投放，潜在买家 [✓]
成功标准:     记住"够安全" [✓]          硬约束: 30s [✓]
核心对象:     智能门锁               七问: 是什么[✓] 在哪[?] 状态[?]
                                     行为[?] 触发[?] 影响[?] 恢复[?]
风格质感:     电影感[模糊] 震撼[模糊]
```

**判定**：P0 基本齐了。现在 P1（核心对象）+ P3（模糊词）可以同轮问。

---

## 第 2 轮（3 问：P1 + 模糊词协议）

> 还差 3 个：
>
> 1. "够安全"要落在什么场景里？（影响：全片的冲突与高潮在哪）
>    可选方向：门外有人试撬 / 家里只有老人小孩独处 / 你人在外地远程看门 —— 或直接描述你想到的画面。
> 2. 这把锁在片子里是"静静待着"还是"主动做动作"？（影响：是否有动作高潮、是否有提示音/灯光反馈）
> 3. 你说的"电影感"，更接近哪一种？（影响：镜头语言与调色方向）
>    ① **调色与对比**：青橙色调、高对比、宽色域
>    ② **媒介质感**：胶片颗粒、浅景深、轻微手持感
>    ③ **运镜语言**：慢推、长镜头、一镜到底
>    ④ **布光**：低调光、单一光源、大面积暗部
>    —— 这四条可以混搭，也完全可以都不按，直接描述你想要的。

## 用户

> 就第三个吧，一镜到底那种。场景……就晚上，一个人回家，门锁一开，屋里灯亮。

## 内部盘点（用户不可见）

```
核心对象: 智能门锁  是什么[✓ 家用智能门锁] 在哪[✓ 夜间住宅门口] 状态[✓ 待机锁闭]
          行为[✓ 识别→开锁→联动灯光] 触发[✓ 户主晚归接近] 影响[✓ 家门+室内灯]
          恢复[~ 默认跳过：30s 一次性视频无"复位"叙事需求]
风格质感: 电影感[✓ 运镜语言：一镜到底]  震撼[仍模糊]
```

**判定**：仅剩"震撼"未澄清、以及 P2 硬约束（品牌露出 / 禁忌）——只剩 1 轮。

---

## 第 3 轮（2 问）

> 最后 2 个：
>
> 1. 你说的"震撼"，希望来自哪里？（影响：高潮怎么设计）
>    可选方向：**尺度对比**（门锁特写 vs 整个夜晚的城市）／**信息密度**（开锁瞬间叠加多重识别过程）／**声画冲击**（低频音 + 慢镜）
> 2. 有没有必须出现的品牌元素，或绝对不能出现的东西？（影响：能不能用真实犯罪画面、是否能露 LOGO）

## 用户

> 震撼就靠声音吧，关门那一下要有分量感。LOGO 最后 2 秒出，别用撬锁的暴力画面。

## 内部盘点（用户不可见）

```
风格质感: 电影感[✓ 一镜到底]  震撼[✓ 声画冲击：低频 + 关门重音]
硬约束:   30s[✓] 抖音[✓] 尾 2 秒 LOGO[✓] 禁暴力撬锁画面[✓]
```

**停止判定（§6.1）**：谁用[✓ 抖音潜在买家] 要什么[✓ 30s 一镜到底脚本] 怎么算成功[✓ 记住"够安全"] 硬约束[✓] → **足够，不再追问。**

---

## 出口

```
# 任务 Prompt
1. 角色与目标
   为智能门锁品牌写一条 30 秒抖音投放短视频脚本，核心目标是让潜在买家记住"这把锁足够安全"。
2. 输入
   产品：家用智能门锁（夜间场景、户主晚归）
   叙事素材：夜晚住宅楼道 → 走近 → 开锁 → 室内灯亮 → 关门
3. 约束
   - 一镜到底（运镜语言为"电影感"的确认解读）
   - 全片 30 秒，尾 2 秒出现品牌 LOGO
   - 禁止出现撬锁、暴力破坏画面
   - 声音设计承担"震撼"：低频铺底，关门瞬间给重音
4. 输出格式
   分镜表（镜号 / 时间码 / 画面描述 / 声音设计 / 字幕），一镜到底不切镜
5. 验收标准
   - 30 秒内讲完"晚归→安全进门"，不出现产品参数朗读
   - 观众能感到"安全"来自门锁，而不是来自环境
   - 结尾 LOGO 不超过 2 秒，全程无暴力画面

## 待确认假设
- "安全"主要通过"开锁即联动室内灯"来体现（由你说的"门锁一开屋里灯亮"推出，若不符请指出）
- 片中不出现真人正脸，只用背影与手部特写（未与你确认）
```

---

## 这个例子示范了什么

| 行为 | 对应规则 |
|---|---|
| 用户第 1 句就带着两个模糊词，仍然先问 P0 目标 | 规则 3（优先级） |
| 每轮 2～3 问，没有一轮超过 3 个 | 规则 2 |
| "电影感"给 4 条**正交**方向（媒介/运镜/调色/布光），并明确允许不按选项 | 规则 5、6 |
| 用户选的"一镜到底"被写进约束，未被改写 | 规则 4 |
| "震撼"用目的反推（问希望来自哪里）而非照抄 | 规则 5 |
| 七问中"恢复"判定为可默认并跳过，没有机械问满 | 规则 7 |
| 信息足够后第 3 轮即收尾，未追问预算/风格/平台细节 | 规则 8 |
| "开锁联动灯""不露正脸"两条是我推的 → 只进「待确认假设」 | 规则 4 |
