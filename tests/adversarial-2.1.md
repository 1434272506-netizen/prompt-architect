# 对抗测试 · §2.1 环境信息唯一出口（V0.1 · 已冻结）

> **状态：固定回归项。** A1～A12 共 12 例，§2.1 冻结后任何改动都必须让这 12 例继续通过。追加新案例须先证明"裁定顺序 5 步走完仍得不出唯一答案"。

**测试目标**：只验证**现行规则**能否稳定裁定"环境/工具/资源状态要不要告诉用户"，不新增规则。
**被测规则**（`SKILL.md` §2.1）：

> 只有当环境、工具或资源状态**会改变用户当前能够获得的结果**，并且**用户需要据此做决定、补充信息或采取行动**时，才向用户说明。只描述实际影响和下一步，不暴露内部工具名、挂载状态、路径、管道、诊断码或执行机制。若 AI 可以自行降级处理且不显著影响结果，则不主动提及。
>
> **判断句**：如果用户知道这条环境信息之后，不需要改变任何决定或行动，就不要说。

**裁定口径**：`稳定` = 依现行规则（唯一出口 + 判断句 + §7 双轨 + §8 假设区）只能得出同一答案；
`无法稳定判定` = 两种读法都说得通，或规则未覆盖该分支。

---

## A1 · 内部工具故障，但不影响结果
- **用户输入**：`把这段会议记录整理成待办清单`
- **内部状态**：`fallback_active`（首选摘要模型超时，自动切备用模型，输出质量无差异）
- **是否应该告诉用户**：**不说**
- **正确用户侧表达**：（无环境说明）直接给出待办清单
- **错误示例**：`首选模型超时，已自动切换到 backup-2 模型处理。`／`摘要服务降级中。`
- **判定理由**：判断句——用户知道后不需要改变任何决定或行动；结果未变。
- **覆盖判定**：**稳定**

---

## A2 · 内部工具故障，并降低结果质量（不阻塞）
- **用户输入**：`帮我给这 30 条评论做情感倾向统计`
- **内部状态**：`confidence_low`（统计脚本可跑，但精细度模型不可用，只能按关键词粗分，准确率下降）
- **是否应该告诉用户**：**应该**，用一句业务语言说明限制
- **正确用户侧表达**：`可以出结果，但这一版只能按关键词粗分，倾向判断会偏粗；如果你要更准的分类，我需要换一种做法再跑一次。`
- **错误示例**：`细粒度分类模型不可用（service=ner-v3, code=503），已降级到 keyword_fallback。`
- **判定理由**：结果的可信度受限，用户需要据此决定是否采信或改方案。
- **覆盖判定**：**稳定**（裁定顺序第 2 步：实质降低结果准确性/可信度 → 说明限制）
- **裁定依据（已写入 `SKILL.md` §2.1）**：结果质量优先于可行动性——即使环境限制已经实质降低结果的准确性、完整度、可信度或完成度，**即使用户此刻没有可采取的动作**，也要说明；只说明结果受限在哪里，不解释内部故障机制。

---

## A3 · 缺失用户文件，任务无法继续
- **用户输入**：`按我昨天发你的那份合同改一版`
- **内部状态**：`resource_missing`（附件未收到 / 无法读取）
- **是否应该告诉用户**：**应该**
- **正确用户侧表达**：`我这边没有拿到你说的合同原文，现在无法按它改。请重新发一次，我拿到原文再动手。`
- **错误示例**：`读取失败：path=\\share\...，errno=2。`／`附件解析模块不可用。`
- **判定理由**：用户必须补充信息（重新上传）才能继续 → 判断句要求说；且这是"缺输入"不是"报环境"。
- **覆盖判定**：**稳定**

---

## A4 · 缺失可选资源，但可正常继续（且降级产生可感知替代）
- **用户输入**：`做一个数据看板的页面原型`
- **内部状态**：`tool_unavailable`（在线图表库不可用 → 自行用纯 CSS 画了简化图表）
- **是否应该告诉用户**：环境原因**不说**；若替代形态用户可感知，只把**方案替代**放进「待确认假设」区
- **正确用户侧表达**：正文不提环境；结尾假设区：`- 图表先用简化的纯 CSS 图形表示，未使用现成图表库绘制（若你要更精细的图表请指出）`
- **错误示例**：`图表库 CDN 不可达，已 fallback 到纯 CSS 实现。`（报环境）／完全不提任何替代（用户不知道拿到的是简化图）
- **判定理由**：环境不影响"能否继续"；但交付形态变了，属于用户未确认的替代结果。
- **覆盖判定**：**稳定**（裁定顺序第 3 步：产生改变原始意图的替代结果 → 说明替代，需要时请求确认）
- **裁定依据（已写入 `SKILL.md` §2.1）**：静默降级的分界——降级不可感知 → 完全静默；降级造成用户**可感知且可能改变其原始意图**的替代 → 只描述替代结果，需要选择时才列为待确认项，不解释内部降级原因。
  - 高清图稍变低清、仍满足需求 → 说明质量限制，不请求确认
  - 要 PDF 只能给 DOCX → 必须确认
  - 无实时价格、只能用历史价格 → 必须明确告知
  - 本例（图表库不可用 → 简化图形）：形态可感知且可能不符预期 → 作为待确认项，表述为"图表先用简化图形表示"（不出现图表库/CDN 字样）

## A5 · 无法访问实时信息
- **用户输入**：`这几个型号现在多少钱？给我排个推荐顺序`
- **内部状态**：`dependency_failed`（无实时数据通道，只能用离线知识）
- **是否应该告诉用户**：**应该**，说明限制并给出替代方案
- **正确用户侧表达**：`当前无法核实实时价格，所以这一部分我只能先给出不依赖实时数据的方案（按定位和参数排），价格需要你确认后再补。`
- **错误示例**：`实时行情接口调用失败（ticker-api）。`／什么都不说但把价格当事实给出
- **判定理由**：影响结果可信度，用户需要决定是否接受/自行核价。
- **覆盖判定**：**稳定**

---

## A6 · 用户主动询问系统状态
- **用户输入**：`你是不是出问题了？怎么这么慢`
- **内部状态**：`dependency_failed`（检索通道不可用，任务改用本地知识完成，交付不受影响）
- **是否应该告诉用户**：**应该回答**（用户主动问），但不解释机制
- **正确用户侧表达**：`刚才确实有点慢，不过你要的东西我已经给全了，不影响结果。如果你要更全的资料来源，我可以稍后再补一版。`
- **错误示例**：`对，检索模块 dependency_failed，已 fallback 到本地知识库。`／`我不方便说明系统状态。`（拒答）
- **判定理由**：属于用户提出的问题，不回答等于回避；同时仍受"不暴露工具名/诊断码/路径"约束。
- **覆盖判定**：**稳定**（裁定顺序第 4 步：用户主动询问 → 回答用户层面的影响与可行动作）
- **裁定依据（已写入 `SKILL.md` §2.1）**：用户主动询问当前能力/状态时**不拒绝回答**；用业务语言说明"能否完成 / 哪些结果受影响 / 是否需要采取行动"；默认不暴露工具名、挂载路径、诊断码、日志、实现管道；**若存在能实际解决问题的用户动作，可以明确告诉用户**（重新上传、稍后重试、重新授权等）。

---

## A7 · 环境异常但存在自动 fallback，结果不变
- **用户输入**：`把这个表格转成 CSV`
- **内部状态**：`fallback_active`（首选转换器报错，备用转换器成功，输出一致）
- **是否应该告诉用户**：**不说**
- **正确用户侧表达**：（无环境说明）直接给 CSV
- **错误示例**：`首选转换器失败，已用备用通道完成。`
- **判定理由**：判断句——无需改变任何决定或行动；结果一致。
- **覆盖判定**：**稳定**

---

## A8 · fallback 会明显改变交付结果
- **用户输入**：`按这段口述写一份两页的产品说明`
- **内部状态**：`fallback_active`（长文生成通道不可用 → 只能输出要点大纲，篇幅明显不足）
- **是否应该告诉用户**：**应该**，说影响 + 给选择
- **正确用户侧表达**：`这一版我先给到要点大纲，还不到两页的成稿。要成稿的话我换个写法再来一版，或者你告诉我最想保留哪几段。`
- **错误示例**：`文本生成服务降级中，仅输出 outline 模式。`
- **判定理由**：交付形态明显偏离要求 → 用户需决定是否接受。
- **覆盖判定**：**稳定**（"明显"没有量化阈值，属判断余量，但方向唯一）

---

## A9 · 技术错误信息含路径、工具名或诊断码
- **用户输入**：`继续把上次那份报告写完`
- **内部状态**：`resource_missing`，底层报错原文：`ENOENT: C:\Users\...\reports\q3.docx (errno 2, trace=ab12ff)`
- **是否应该告诉用户**：**应该**，但必须脱敏——只留影响和行动
- **正确用户侧表达**：`我找不到上次那份报告的原件，没法接着写。你重新发一次或直接把内容贴给我都行。`
- **错误示例**：`ENOENT: C:\Users\...\reports\q3.docx (errno 2, trace=ab12ff)`
- **判定理由**：收紧版明确禁止路径、管道、诊断码、执行机制。
- **覆盖判定**：**稳定**

---

## A10 · 用户实际上不需要知道的环境异常
- **用户输入**：`帮我起 10 个标题`
- **内部状态**：`dependency_failed` 后自愈（缓存写满已自动清理，无用户可见影响）
- **是否应该告诉用户**：**不说**
- **正确用户侧表达**：（无环境说明）直接给标题
- **错误示例**：`刚才缓存接近上限，已自动清理，请放心。`
- **判定理由**：判断句直取"不需要改变任何决定或行动 → 不要说"。
- **覆盖判定**：**稳定**

---

## A11 · 多个异常叠加，其中一个阻塞任务
- **用户输入**：`用我上传的 Excel 出个月度报表`
- **内部状态**：`resource_missing`（表格没收到，阻塞）＋ `tool_unavailable`（图表库不可用，非阻塞）
- **是否应该告诉用户**：只说**阻塞项**及所需行动；非阻塞项静默处理
- **正确用户侧表达**：`我这边没收到那份 Excel，报表没法开始。请重新上传；收到后我直接出月度报表。`
- **错误示例**：把两条都倒出来：`文件缺失；图表库不可用已降级…`
- **判定理由**：用户只需对阻塞项采取行动；非阻塞项的暴露不改变任何决定。
- **覆盖判定**：**稳定**

---

## A12 · 环境异常影响的是后续能力而非当前结果
- **用户输入**：`把这段分析发我，我要拿去开会`
- **内部状态**：`dependency_failed`（本次结果已完整，但会话内容无法自动保存/找回）
- **是否应该告诉用户**：**应该**，一句提示 + 需要他做的动作
- **正确用户侧表达**：`内容已经齐了。这次的内容不会自动留存，你最好现在就复制或下载一份带走。`
- **错误示例**：`会话存储服务不可用，persist=false。`
- **判定理由**：用户当下需要采取行动（自行保存）→ 判断句成立。
- **覆盖判定**：**稳定**

## 汇总

| 案例 | 场景 | 裁定 | 现行规则是否稳定 |
|---|---|---|---|
| A1 | 工具故障不影响结果 | 不说 | 稳定 |
| A2 | 工具故障降低质量 | 说（说明限制） | 稳定（裁界①） |
| A3 | 缺用户文件、无法继续 | 说 + 行动 | 稳定 |
| A4 | 缺可选资源可继续（有可感知替代） | 环境不说，替代进假设区 | 稳定（裁界②） |
| A5 | 无法访问实时信息 | 说（限制 + 替代） | 稳定 |
| A6 | 用户主动询问系统状态 | 回答（业务语言） | 稳定（裁界③） |
| A7 | 自动 fallback，结果不变 | 不说 | 稳定 |
| A8 | fallback 明显改变结果 | 说（影响 + 选择） | 稳定（有判断余量） |
| A9 | 报错含路径/工具名/诊断码 | 说，但脱敏 | 稳定 |
| A10 | 用户无需知道的环境异常 | 不说 | 稳定 |
| A11 | 多异常叠加、其一阻塞 | 只说阻塞项 | 稳定 |
| A12 | 影响后续能力，用户需行动 | 说（行动提示） | 稳定 |

**结论**：12 例**全部可稳定裁定**（A2/A4/A6 由 §2.1 新增的三条裁界 + 「裁定顺序」5 步收口）。

**本轮修正（已写入 `SKILL.md` §2.1）**

1. **结果质量优先于可行动性**（覆盖 A2）：只要环境限制实质降低了准确性/完整度/可信度/完成度，就说明，**即使用户没有可行动作**。
2. **静默降级的分界**（覆盖 A4）：不可感知 → 完全静默；可感知**且可能改变原始意图** → 描述替代结果，需要选择时才列为待确认项（不是所有可感知变化都要确认）。
3. **用户主动询问能力/状态**（覆盖 A6）：不拒答；说清"能否完成 / 影响哪些结果 / 是否需要行动"；不暴露工具名、路径、诊断码、日志、管道；**能真正解决问题的用户动作要明确说出来**（重新上传/重试/重新授权）。

**状态：A1～A12 转为固定回归项，§2.1 冻结。** 只有在出现"裁定顺序 5 步仍无法得出唯一答案"的新案例时才重新打开。
