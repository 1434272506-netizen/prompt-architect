# Interface v3 · Canonical Migration Manifest

> **用途**：v3 迁移测试的**规范案例清单**。先固定"要跑什么"，再谈结果。
> **纪律**：**不静默去重**——重复只显式标注 **alias（精确别名）**或 **overlap（场景类重叠）**。
> **本文档只登记，不写规则、不改任何冻结正文。**

---

## 0. 术语

| 术语 | 定义 |
|---|---|
| **Raw（原始案例）** | 各测试文件中**逐条编号**的案例总数 |
| **AL（精确别名簇）** | **同一用户原话 + 同一上下文 + 同一期望跃迁** → 计为 1 个唯一场景 |
| **OC（场景类重叠）** | 同类情景但措辞/上下文/验证目的不同 → **各计 1 个**，仅标注重叠 |
| **Unique Scenario（唯一场景）** | Raw − Σ(AL 簇内成员 − 1) |
| **Fixed Regression（固定回归）** | 必须每次执行的 canary；**不参与去重删除**（即 alias 也照跑） |
