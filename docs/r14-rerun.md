### 0.2 判定口径（供 Lead 复核）

- **R6 闭集**：目标 / 范围 / 权限 / 费用 / 数据用途 / 不可逆操作（**不含受众** —— D11 修复；**不含成功标准**）。
- **R6 闭集边界（V0.3.6 裁定）**：只含**产品级边界与对外约束**；**P1 内容细节（抽取字段、工作流、布局、文案、命名）与 P2 实现细节不属于 R6** → 这些槽位**不得触发**同轮并列（A3/M8 的"抽取字段"、M6/S3 轮2 的"工作流"因此不进轮1）。
- **同轮并列的复核对象（V0.3.7）**：**两侧都要查** —— ①原本被推迟的槽位；**② 该风险自身对应的 R6 槽位（权限风险↔权限范围、合规/数据风险↔数据用途、资金风险↔费用授权、不可逆风险↔不可逆操作边界）**，后者默认视为未定的必问项。判据句不变：**"教了这个风险，却不拿到这个答案，用户能定吗？"**
- **闸门③（本报告统一口径）**：必须能指出本项目中**具体载体（哪个字段/哪条数据流/哪个操作）+ 不处理的后果**；只能给出"风险名 + 项目名"（如"权限模型 + 内部工具"、"数据安全 + 数据报表"）→ **不通过**。
- **两个数字**：**M3** ＝ 动作迁移但前提不成立（`migration-framework.md` §2）；**R14 改动影响例数** ＝ 在 V0.3.7 现行文本下重判后**与原判定不同**的例数。
