## rc.1 → rc.2（发布前复核抓到的缺陷，已修）

**Release Reproducibility Check**：从 `v0.4.0-rc.1` 建 fresh worktree 后，三 Gate 在**干净检出**中失败：

```
FRG-01 V0.3  MATCH 0  DIFF 24   exit 1
FRG-02 V0.4  MATCH 1  DIFF 20   exit 1
FRG-07       28/28              exit 0
```

**根因**：**行尾规范化**（`i/lf  w/crlf`）——index 存 LF、工作区为 CRLF ⇒ 干净检出得到 LF 字节 ⇒ 与按 raw bytes 计算的冻结哈希不一致。

**修复（rc.2 所含）**：

```
① .gitattributes :  * -text                        （禁止一切行尾转换）
② git config core.autocrlf false
③ git add --renormalize .                          （index ＝ 工作区原始字节）
④ fresh worktree 复验 → MATCH 24 / MATCH 21 / 28-28，全 exit 0
```

**纪律**：`v0.4.0-rc.1` **tag 不移动**（保留为历史标记，记录缺陷发现），修复以**新 commit ＋ 新 tag** 表达。
